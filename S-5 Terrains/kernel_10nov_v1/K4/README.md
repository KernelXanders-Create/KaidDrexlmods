# KERNEL_RETURN_10NOV_K4: the alien layer board (Islands "Ember Caldera", PROPOSED)

Job K4 from the 10 Nov pack: three ways to make the Aegean clearly not Earth, one page each, with the references I found and what each teaches. Facts and looks only, with **no ranking**.

## What is in this zip
| File | Way |
|---|---|
| `A_CORAL_SHORE.md` | (A) a coral shore: pink and red sand, red coral heads, Mediterranean vermetid platforms, raised-coral spikes |
| `B_ALIEN_SCRUB.md` | (B) alien scrub and trees in non-Earth colours: Socotra umbrella and bottle trees, red Teide spires, red seepweed flats, spiny thickets, silver rosettes |
| `C_CRYSTAL_LAVA.md` | (C) crystal veins in black lava: amethyst geodes in basalt, Lipari obsidian, green olivine sand, black column beaches, hydrothermal colour, blue sulfur fire, Naica for scale |

Each page has:
- a reference table: link, what it shows, what it teaches;
- design notes on where it would sit on Ember Caldera, using the purpose map's existing places;
- which owned assets it leans on (REV2 list);
- engine notes (simple objects, satellite texture for the distant read);
- facts to keep straight.

The three are not exclusive. They can sit on different zones of the same map.

## How the references were found
- Web searches on 11 Nov 2026.
- **The links are to pages with photos or source text. I did not view, download or embed any images,** so there are no image files in this zip. Please open the links and judge the looks yourselves.
- Where sources disagree on a fact (Komodo's pink cause, the Rocche Rosse age, Naica crystal size), the pages say so.
- Some links are travel or outreach sites rather than encyclopedias, and they are marked by their domain.
